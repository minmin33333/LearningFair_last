# LearningFair_last
21팀 시골쥐들 팀 최종 결과물 소스코드

<<셤포터즈: 지능형 공부 스케줄러>>
의사결정 매트릭스 + 에빙하우스 망각곡선을 기반으로 시험 기간 동안의 학습 시간을 과목별로 자동 배분해주는 python 기반 프로그램입니다.


# 주요 기능
- 의사결정 매트릭스 기반 과목별 우선순위 계산
- 시험일까지 남은 시간 자동 반영
- 날짜별 학습 스케줄 생성 및 에빙하우스 망각곡선 기반 복습 스케줄 분배 (기본 14일)
- 원형 차트로 과목별 학습 시간 비중 한눈에 보기


# 프로젝트 구조
21_시골쥐들_셤포터즈/
├── main.py                # tkinter GUI + matplotlib 차트 + 실행 코드
├── scheduler_core.py      # 과목 데이터 / 우선순위 / 스케줄 생성 알고리즘
├── constants.py           # 가중치, 복습 비율 등의 상수 모음
├── install_matplotlib.py  # matplotlib 설치 도우미
└── readme.txt


# 시작하기
0. matplotlib 설치 (선택)
해당 코드를 실행하기 위해서는 matplotlib 라이브러리가 필요합니다. 사용 중인 파이썬 환경에 matplotlib이 설치되어 있지 않다면, 먼저 'install_matplotlib.py' 파일을 실행하여 라이브러리를 설치해 주세요. 설치가 정상적으로 완료되면 터미널에 matplotlib의 버전 정보가 출력됩니다. 이미 matplotlib이 설치되어 있는 경우에는 이 단계를 건너뛰어도 되지만, 설치 상태를 확인하기 위해 한 번 실행해 보는 것을 권장합니다.

1. 코드 실행
'main.py'를 디버깅하면 셤포터즈의 창이 등장합니다. 
나타난 창은 꼭 전체 화면으로 키워주세요! 창이 작으면 일부 버튼이 보이지 않을 수 있습니다.


# 프로그램 구성
1 입력 탭
- 기본 설정에서 오늘 날짜(MM/DD), 하루 학습 시간, 스케줄 기간(일)을 입력합니다.
- 과목 정보를 입력하고 '과목 추가' 버튼을 누릅니다: 과목명, 미루고 싶은 정도(1~5), 난이도(1~5), 분량(1~5), 전공 여부, 시험 일시(선택)
- 모든 과목 입력이 끝나면 '우선순위 / 스케줄 계산' 버튼을 누릅니다.
+ 삭제: 입력한 과목을 삭제하려면 우측 표에서 해당 과목을 선택한 뒤 '선택 과목 삭제' 버튼을 누르거나(Ctrl 키를 꾹 누르면 여러 과목을 동시에 선택 가능) '전체 삭제' 버튼을 눌러주세요. 

2 우선순위 탭
- 과목별 총점, 긴급도, 학습 시간 비중, 일일 배분 시간을 확인할 수 있습니다.

3 학습 스케줄 탭
- 날짜별 신규학습 / 복습 / 합계 시간이 표 형태로 표시됩니다.
- 노란색 행은 복습일(1·3·7·14일 차)을 의미합니다.

4 한 눈에 보기 탭
- 과목별 학습 시간 비중을 원형 차트로 보여줍니다.
